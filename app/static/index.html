Privacy Policy

Last updated: 1 November 2026

Stock Analyser is a stock-research application. This policy describes the information the application handles when you use it.

Information and how it is used

  • Account information: when you register, your email address and authentication records are handled by Supabase Auth.
  • Watchlist: stocks you save are stored in Supabase PostgreSQL and associated with your account so the list can be synchronised across devices.
  • Analysis requests: ticker symbols and analysis settings are sent to the application's backend. Analysis jobs are processed through GitHub Actions using market data obtained through Yahoo Finance tools, and completed results may be kept in a shared cache.
  • Local browser storage: the application stores active request identifiers in your browser so the request queue can continue to display their status after a reload.

Service providers

The application relies on Supabase for authentication and database services, GitHub for hosted analysis workers and deployment, and Yahoo Finance data accessed through yfinance. Those providers process information under their own terms and privacy policies. Their availability and practices are outside the application's control.

Access and control

Your saved watchlist is available after signing in. You can remove individual saved stocks from the Watchlist tab and sign out from the account panel in Settings. For questions about account-data access or deletion, use the project's GitHub issues page.

Security and changes

Watchlist access is restricted using authenticated requests and database row-level security. No internet service can guarantee absolute security. This policy may be updated as the application changes; the date above will be revised when it does.

About Stock Analyser

Stock Analyser combines market-data indexing with an experimental ARIMA–SVR analysis model. RapidIndex provides five years of history and a 30-trading-day horizon; SlowIndex uses the maximum available history and an approximately one-year horizon. Saved watchlists are refreshed by WatchIndex using the shared RapidIndex cache.

The application is built as a research and learning tool. It does not provide personalised investment recommendations.
